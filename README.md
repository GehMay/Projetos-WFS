## 📖 Sobre o repositório

Este repositório reúne os projetos práticos desenvolvidos ao longo do semestre na disciplina de **Web Full Stack**. Cada aula é organizada em sua própria pasta, acompanhando a evolução do conteúdo — de páginas estáticas em HTML/CSS até aplicações com JavaScript e comunicação cliente-servidor.

## 📂 Estrutura do projeto

```text
Projetos-WFS/
├── Aula-01/   # Fundamentos de HTML e CSS
├── Aula-02/
├── Aula-03/
├── Aula-04/
├── Aula-05/
├── Aula-06/
├── Aula-07/
├── Aula-08/   # Projeto com estrutura cliente-servidor (client/)
├── Imagens/   # Recursos visuais usados nos exercícios
├── Teste/     # Experimentos e testes pontuais
└── LICENSE
```

Cada pasta `Aula-XX` corresponde ao conteúdo praticado em uma aula da matéria, servindo como um histórico de evolução dos estudos ao longo do curso.

## 🚀 Como usar

A maioria dos exercícios é composta por páginas HTML simples, que podem ser abertas diretamente no navegador:

```bash
git clone https://github.com/GehMay/Projetos-WFS.git
cd Projetos-WFS/Aula-01
# abra o arquivo .html correspondente no navegador
```

Para as aulas que envolvem um servidor Node.js (como a `Aula-08`), instale as dependências e rode o servidor a partir da respectiva pasta:

```bash
cd Aula-08/client
npm install
npm start
```
